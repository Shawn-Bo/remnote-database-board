# RemNote 高级表格的 Notion 式数据库体验

本轮目标：为现有 RemNote 高级表格提供 Notion 式表格和看板操作，优先完成筛选、排序、视图配置与原属性写入。用户明确要求先做核心功能；日历、时间线等其他布局后续再做。

2026-11-01 已对照实际 Notion 表格、看板、视图设置界面，校准工具栏、列宽、卡片、侧栏、色彩和浅深主题。参考官方文档 https://www.notion.com/help/views-filters-and-sorts 与 https://www.notion.com/help/boards 。私有数据库截图仅留在本地，不进入公开仓库。

## 本轮范围

- 数据源沿用原标签、属性与 Rem；从高级表格进入时保持原行范围。无熟练度或单选属性的表也能打开。
- “以看板打开”明确选择看板视图，单选列成为分组依据；优先复用对应的已有看板，保留筛选与排序。普通重开与后续刷新仍遵循用户选择的视图。
- 0.3.3 在高级表格节点自身的标题区域增加“打开看板”按钮。只检查当前节点是否为表格，不扫描外层文档的子树、不把外层文档作为数据库入口。内嵌表格可先用原生“以完整页面打开”聚焦，再点击按钮；原属性列菜单继续可用。公开 SDK 没有表格工具栏按钮插槽，当前未向内嵌表格工具栏插入自定义按钮。
- 直接入口从表格的原生标签查询识别数据源，点击时重新读取当前表格行范围；查询否定、多个来源或其他无法明确识别的情况不猜测数据源，提示使用属性列菜单。标题的图片参数与原有属性文本共用兼容处理，原富文本不变。
- 表格与看板视图可创建、命名、复制、切换、删除；各自保存显示属性、筛选、排序和看板分组。
- 筛选支持多个条件的所有/任一匹配；排序支持多个属性和升降序，数字按数值比较，空值置后。
- 看板支持按属性分组、跨列拖动回写、无显式排序时的手动顺序、空组/隐藏组、折叠、卡片尺寸及图片封面。
- 原属性编辑、新建记录、原笔记入口；属性写入保留写前冲突检查、写后回读。
- 看板使用接近整个 RemNote 窗口的空间。0.3.1 打开记录时用 `DocumentViewer` 在侧栏呈现该 Rem 的完整原生页面，包含标题、标签、属性和子节点。完整页面替换了 0.3.0 仅含子节点的 `RemHierarchyEditorTree`；直接编辑原节点，没有插件正文副本、保存记录和正文写回流程。
- 0.3.2 改为并排侧栏：桌面打开原生页面后，左侧数据库仍可切换视图、筛选和选择其他记录；手机宽度下原生页面占满可用空间，关闭后恢复原来的数据库视图。新建记录弹窗打开时暂停呈现原生页面，取消后恢复，避免原生内容覆盖弹窗。
- 正文区域直接呈现当前笔记；旧草稿恢复、版本迁移等维护信息不放进日常编辑界面。
- 手机宽度下采用全宽布局，保留横向滚动和触控拖动把手；常用按钮、拖动把手和属性控件已扩大为至少 44px 高的触摸区域。390 × 844 CSS 像素下的筛选、视图设置、表格横向浏览、属性修改与刷新保留已手动验证；真实设备的触摸和原生完整页面仍需验收。
- 保持插件身份及旧配置兼容，安装器升级替换旧服务。上传按用户安排延后。
